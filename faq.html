Scanning and use

Does a fake ID scan?

The PDF417 resolves to the printed data on a standard bar or club scanner. It does not query a DMV record. Full breakdown on the fake ID page.

Will it pass a bank?

For a teller transaction, usually. For opening an account, expect a possible database check. The Real ID is the better card for bank counters.

Can I fly with a Real ID?

Domestic, usually — TSA compares name and face to the boarding pass. It does not run the number.

Can I fly internationally on a passport?

You can board and you can pass a visual check. A border officer's database lookup is where it stops.

Does the SSN number verify?

Format-correct, yes. A live SSA record, no. E-Verify is unreliable on a replica.

Will a utility bill be accepted?

By letting agents, gyms, phone contracts and parcel depots, usually. Not by a supplier switch.

Do passports have a chip?

Only with the $45 inlay. The base booklet is print only, and we say so on the page.

Can I get stamps in a passport?

No. Wet-ink stamps are issued in person.
